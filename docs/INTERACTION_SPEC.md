# 全局操作规范

本规范对应 Android 扫描、原生游戏、离线棋牌和媒体页面。版本：2026-11-17。

## 页面层级与命名

```text
主页
├─ 应用设置：音量、亮度、模拟控制、耳机控制、扫描速度校准
├─ 实时沟通：字母块、拼音、汉字、预测词、常用语
├─ 娱乐
│  ├─ 迷宫、向上贪吃蛇、魔法师
│  ├─ 中国象棋、斗地主、麻将
│  └─ 音乐、电视
└─ 设备与模型：本地用户、连接、采集、服务器绑定、模型管理
```

- 娱乐子模块返回到娱乐；娱乐返回主页。按钮文案必须说明真实目标。
- 速度校准返回打开它的页面，不固定跳回主页。
- 设备与模型继续作为照护者触摸配置页，不把配置表单纳入患者自动扫描。
- 绿色悬浮球标为“模拟”，用于发送模拟动作，不表示真实耳机控制已启用，也不是助手入口。

## 输入模式

| 模式 | 左看 | 右看 | 咬牙 | 自动变化 |
|---|---|---|---|---|
| 普通扫描菜单 | 扫描方向改为左/前 | 扫描方向改为右/后 | 执行高亮项 | 按设置周期扫描 |
| 确认窗口 | 选择左侧取消 | 选择右侧确定 | 执行已选决定 | 不自动改变决定 |
| 迷宫、贪吃蛇结束二选一 | 选择左侧重开 | 选择右侧返回娱乐 | 执行已选决定 | 不自动改变决定 |
| 迷宫直接控制 | 左移 | 右移 | 上移 | 不自动移动 |
| 贪吃蛇直接控制 | 转向左 | 转向右 | 横行时向上；已向上时打开退出确认 | 按游戏周期移动 |
| 电视观看 | 上一频道 | 下一频道 | 打开操作菜单 | 不自动换台 |
| T9 字母块 | 选择左侧当前块或切到左侧 | 选择右侧当前块或切到右侧 | 进入拼音或常用语选择 | 扫描字母块 |
| 目标校准练习 | 暂停 | 不作答 | 确认高亮目标 | 固定测试顺序 |

普通菜单的左右动作**只改变方向，不同时跳一项**。默认方向从左到右/从上到下，循环越界。棋牌、应用设置、音乐各层菜单、电视操作菜单遵循此规则。直接控制和有明确目标的练习是独立模式，不伪装成普通菜单。

扫描速度沿用 1100～3000 毫秒范围。相同速度的重复设置必须幂等，不得因父页面重组反复重置扫描计时器。

## 确认与结果

- 取消在左、确定在右；初始选中取消。等待多久都不会自动选中确定。
- 左右是明确选择，不是翻转：连续右看仍是确定，连续左看仍是取消。
- 删除、重开未结束对局、离开未结束对局等必须明确确认。斗地主原有可选出牌二次确认设置保留；退出和重开仍单独确认。
- 触摸和 BCI 使用同一决定执行入口。
- 游戏结束后保留结果，用户决定重开或返回；迷宫不再自动重开。
- 实时沟通的原“发送”改称“完成”：现有函数只归档本轮上下文并清空输入，未接入对外消息发送。

## 返回优先级

1. 确认窗口：取消本次决定，恢复上层。
2. 普通弹层/设置菜单：关闭弹层，保留原模块。
3. 分层选择：返回上一选择层；实时沟通保留已完成文本。
4. 模块根页：返回规定父页。未结束游戏先确认退出。

音乐：删除确认 → 删除列表 → 音乐设置 → 播放界面 → 娱乐。
电视：操作弹层 → 观看界面 → 娱乐。
象棋：确认 → 原选择；落点 → 选子；选子 → 选列；选列返回时确认退出。
斗地主、麻将：确认先取消，设置先关闭，再处理退出。

## 指令所有权

- 同一时刻只允许当前页面或最上层弹层处理语义动作。
- 页面切换、确认/设置层切换、前后台切换会作废尚未投递的识别结果。
- 普通 Activity 在后台不接收真实耳机或悬浮球操作。
- 魔法师 Activity 只在前台接收游戏指令；仅注册了旧消费者不能抢占其他页面的输入。
- 真实耳机仍受连接状态及用户控制开关约束；断流后不自动绕过既有的手动启用流程。
- 旧 WebView 的异步回调不得退出新页面；销毁后不再接受其状态回报。
- 打开菜单不会把确认动作同时交给底层游戏，也不会在恢复后补执行积压动作。

## 当前边界

- 魔法师主体是已有 Godot `.pck`，本次统一 Android 宿主的前台输入路由；包内动作和菜单未重写或逐项验收。
- 没有新增双咬牙、长咬牙或全局助手唤起手势。
- EEG 识别类别、模型合同和判定阈值不因交互规范而改变。
